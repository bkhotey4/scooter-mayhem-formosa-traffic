# 自由探索街區擴建 — 2026-10-05

延續上一輪已核准的大地圖工作。Web 原型的活動邊界擴為 156 × 416 公尺（原約 84 × 352），目前仍是各縣市共用街區，不是獨立縣市地圖。

- 保留中央送單街區、既有交通及美食集章。新增西側河堤、東側住宅／夜市支路、南北環道；三條橫街穿過外圍街廓缺口連接外環。

- 小公園／休息站加入樹木與座椅；地標招牌兩面可讀。新區域目前以探索為主，未增加外送訂單或外環動態車流。
