### 四、 如何於本地啟動與測試

1. **立即體驗 3D 網頁原型**：
   * 開啟瀏覽器造訪：`http://localhost:3001/`
   * 操作方式：
     * **W / ↑**：油門催下去（極速 75 km/h，拾取結冰水氮氣爆衝可達 120 km/h！）
     * **A D / ← →**：左右靈活轉彎壓車（傾角連動珍奶晃動）
     * **Shift / Q**：神之翹孤輪遮牌（前輪抬起、避開測速相機）
     * **空白鍵（Space）**：甩尾急煞
     * **H**：按喇叭（逼退巷弄黑狗、向土窯雞發財車打招呼）
     * **T**：切換時間與氛圍天氣（逢甲黃昏 ➔ 通化深夜霓虹 ➔ 狂暴雷雨閃電）
     * **1 ~ 7**：快速瞬移切換全台 7 大縣市專屬路況
     * **C**：切換第三人稱追焦視角 / 第一人稱龍頭視角
     * **R**：機車原地擺正重生
     * **壓在路旁水溝蓋上**：啟動「水溝蓋跑法」火花噴射加速！
