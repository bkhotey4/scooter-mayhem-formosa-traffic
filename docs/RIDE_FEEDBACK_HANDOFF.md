# Gemini 最新版本接手：騎乘回饋

保留既有懸吊、巷道、路面補丁、減速丘、車友連線與維修功能。本次針對實際玩家體驗整合，沒有重新製作地圖或替換連線架構。

- 預設舒適鏡頭：固定 60 度視野、取消鏡頭側傾與路面抖動、降低推拉及懸吊跟隨。Esc 暫停選單可切回原動感模式；localStorage 記住鏡頭偏好，儲存失敗不影響遊戲。
- 懸吊使用解析阻尼彈簧；貨物的衰減震動訊號不再每幀重複施力。水溝改為位置相關的路面高度回饋，保持原先加速功能。
- 煞車燈獨立材質，煞車時變亮、放開或重生復原；避免改變其他車的共用材質。
- 車手名稱、房間代碼等輸入欄位不觸發行車或地區快捷鍵。
- 攝影機位置跟隨改為時間一致的指數平滑。
