## 🛠️ 最佳模型製作與優化建議 (仿 GTA 台北畫風)

1. **面數控制 (Poly Count)**：
   - 機車車體：建議 **3,000 ～ 10,000 三角面 (Tris)**。
   - 汽車車體：建議 **4,000 ～ 15,000 三角面 (Tris)**。
2. **中心點與座標軸 (Pivots & Coordinates)**：
   - **車頭朝向**：Z 軸正向 (+Z) 或負向 (-Z)（引擎內建自動鏡像與轉向補償）。
   - **底盤接地點**：將輪胎最低點對齊 Y = 0，中心對齊 X = 0。
3. **材質與貼圖 (PBR Materials)**：
   - 推薦使用標準 PBR 材質（Metalness: 0.1~0.8, Roughness: 0.2~0.6）。
   - 貼圖解析度 1024x1024 或 2048x2048 即可兼顧細節與秒開效能。
4. **推薦免費模型庫**：
   - [Sketchfab (可篩選 Downloadable / Free)](https://sketchfab.com)
   - [Poly Pizza (Low-poly 輕量模型)](https://poly.pizza)
   - [CGTrader (Free 3D Models)](https://www.cgtrader.com)
